# Job Copilot

## Design Context

### Users
Primary viewer in the demo: hackathon judges from Convex, OpenAI, Firecrawl, AgentMail, scanning fast, credibility-sensitive, technically expert. Secondary: everyday job seekers (a hunted, phishing-target audience). The product is an AI job-search copilot whose spine is a **trust registry**: domains ranked by observed authenticated-email behavior, queryable by agents.

### Brand Personality
Three words: **rigorous, factual, a little severe.** It is a *ledger of proof*, not a marketing page. Voice: plain, declarative, evidence-first. It should make a technical judge think "this person understands infrastructure," and make a job seeker feel *safe and in control*. Emotional goal: earned trust.

### Aesthetic Direction
**Dark terminal-minimalist**, derived from real context: the primary judges built AgentMail, whose entire world is dark zinc (#09090b), mono-forward, hairline-bordered, "a terminal wrapped in a shadcn dashboard" (Resend is the same camp). Sitting in that neighborhood speaks the judges' dialect AND is genuinely more credible for a **certificate log / trust registry** (the crt.sh/SSL-Labs "provably true" register works in dark too when it's dense + mono + factual). We are compatible-but-distinct: same dark zinc base and mono-for-data, but our own identity via one signature motion object and the registry-as-hero structure (NOT AgentMail's ASCII texture, NOT a Stripe-scale globe).
- **Palette (dark, cool zinc):** bg near-black `#0a0a0c`, surface `#141417`, hairline border `rgba(255,255,255,0.08)`, text `#fafafa`, muted text `#9a9aa4`. Tinted very slightly cool. One restrained accent (indigo/blue ~`#5b6cff`) at ~10% weight, interaction + sort affordance only.
- **Semantic (verdict) color ONLY:** green `#4aa651` (verified), amber `#e49e22` (couldn't-verify/neutral, calm not alarmist), red `#ff6568` (flagged). Nothing else is saturated.
- **Fonts:** Public Sans for UI/chrome (official-record character, deliberately NOT Inter/Space Grotesk); Spline Sans Mono for ALL data (domains, scores, grades, timestamps) — mono is the identity element, as in AgentMail/Resend, not lazy dev shorthand.
- **Signature motion:** ONE ambient domain node-graph (canvas) — domains as nodes sized by earned trust; a faint arc pulses between nodes when a new authenticated email lands. The registry IS the network. Restrained, like Resend's single cube. No globe, no particles-everywhere.
- **Anti-references:** gradient trust bars, radial gauges, rounded floating stat cards, everything-centered, glassmorphism, AgentMail's exact ASCII texture, a Stripe/GitHub marketing globe.

### Design Principles
1. **The table is the hero.** Density is credibility. Facts in monospace, left-aligned, hairline-ruled. Never hide data in cards.
2. **One glanceable verdict per row** (a flat colored grade box), backed by the evidence that earned it. Click-to-verify, never a black box.
3. **Color means state, nothing else.** Green = verified, amber = couldn't-verify/neutral, red = flagged. The middle state is calm, never alarmist ("couldn't verify" ≠ fake).
4. **Restraint over decoration.** 60/30/10 weight. If it doesn't encode a fact, it doesn't earn color or motion.
5. **Motion conveys state change only** (a row/card entering as email lands), 150-300ms, transform/opacity, reduced-motion respected.
